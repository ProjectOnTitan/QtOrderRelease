# 下載檔案與更新清單都由公開的 QtOrderRelease 提供

QtOrder 的原始碼在私有 repo，但版本與發布統一由 GitHub 控管，取代原本手動上傳 GCS：下載檔案放在公開的 QtOrderRelease 的 GitHub Releases，更新清單與發布中心一起部署在 GitHub Pages，兩者都由 `data/releases.json` 這份發布紀錄產生，任何發布、晉升、撤回都經 PR 審核後才生效。決定時還沒有客戶安裝 QtOrder，啟動器內寫死的更新位址還能改。

## Consequences

- **上線前提**：安裝程式與更新套件不得含任何金鑰。原本的 BullionTrader 打包流程會把 GCP 服務帳號金鑰放進檔案；在金鑰移出之前，發布中心只放模擬資料，不發布真實的下載連結。
- 程式沒有數位簽章，更新清單附上更新套件的 SHA-256 與大小，由啟動器下載後比對，作為唯一的完整性檢查。
- GitHub Pages 約有 10 分鐘快取，發布後客戶最多晚 10 分鐘看到新版本。
- 之後若要把檔案移出 GitHub，必須在客戶的啟動器還能更新位址時進行；有客戶安裝之後，搬遷就需要所有人重新安裝。
